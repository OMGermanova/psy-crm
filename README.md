# Кабинет — CRM для психолога

Демонстрационная CRM: клиенты, сессии, оплаты, ближайшие встречи.
Одна страница, без сборки, без зависимостей, без сервера.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка страницы, три раздела и три диалоговых окна |
| `styles.css` | Оформление: спокойная палитра, карточки, адаптив под телефон |
| `app.js` | Логика: данные, подсчёты, фильтры, формы |

## Как запустить локально

Двойной клик по `index.html` — откроется в браузере. Ничего устанавливать не нужно.

## Как опубликовать и получить ссылку

Все три способа бесплатны. Папка целиком — это и есть готовый сайт: собирать ничего не надо.

**1. Netlify Drop — самый быстрый (нужен аккаунт, вход по почте или GitHub)**

1. Открыть <https://app.netlify.com/drop>
2. Перетащить папку `psy-crm` в окно браузера
3. Через несколько секунд появится адрес вида `https://имя.netlify.app`
4. В настройках сайта можно сменить имя на понятное, например `kabinet-demo`

**2. Cloudflare Pages**

1. <https://dash.cloudflare.com> → Workers & Pages → Create → Pages → Upload assets
2. Загрузить те же три файла, получить адрес `https://имя.pages.dev`

**3. GitHub Pages — если хочется держать код в репозитории**

```bash
cd psy-crm
git init
git add .
git commit -m "Кабинет: демо-версия CRM для психолога"
git branch -M main
git remote add origin https://github.com/ЛОГИН/psy-crm.git
git push -u origin main
```

Затем в репозитории: Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
Адрес будет `https://ЛОГИН.github.io/psy-crm/`.

## Что важно помнить

- **Данные хранятся в браузере зрителя** (`localStorage`), а не на сервере. Каждый, кто откроет ссылку, увидит демо-набор и сможет его менять — у себя, не у вас. Между устройствами данные не синхронизируются.
- **Не вносите реальные данные клиентов** в публичную версию. Всё, что введено на странице, остаётся в браузере того, кто вводил, но публичный адрес — не место для настоящих записей: сведения о психологическом состоянии относятся к специальной категории персональных данных.
- Перед использованием на реальных клиентах нужен сервер с базой, входом и правами доступа, плюс разговор с юристом про 152-ФЗ (хранение в РФ, согласие на обработку, уведомление РКН).

## Сохранение и выгрузка данных

Кнопка **«Данные»** в шапке:

| Пункт | Что делает |
| --- | --- |
| Сохранить копию | Скачивает `.json` со всеми клиентами и сессиями. Это резервная копия — её можно загрузить обратно |
| Загрузить копию | Восстанавливает базу из ранее сохранённого `.json` |
| История изменений | Последние 10 состояний базы с возможностью откатиться к любому |
| Таблица для Excel | Два файла `.csv` (клиенты и сессии), кириллица с BOM — Excel откроет без настройки кодировки |
| Версия для печати | Сводка в новом окне: можно распечатать или сохранить в PDF |

JSON — для восстановления без потерь. CSV и печать — чтобы посмотреть глазами или показать другому человеку.

## Версии

Метки в git: `v1.0` — первая версия, `v1.1` — часы и мобильная вёрстка, `v1.2` — сведение историй, `v1.3` — копия данных и история, `v1.4` — выгрузка CSV и печать.

Откатиться к версии: `git checkout v1.1`.

## Демо-данные

При первом открытии подставляются пять вымышленных клиентов и восемь сессий — чтобы интерфейс не был пустым.
Кнопка «Сбросить демо-данные» внизу страницы возвращает этот набор.
