# Кабинет — CRM для психолога

Демонстрационная CRM: клиенты, сессии, оплаты, ближайшие встречи.
Одна страница, без сборки, без зависимостей, без сервера.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка страницы, четыре раздела и диалоговые окна |
| `styles.css` | Оформление: спокойная палитра, карточки, адаптив под телефон |
| `app.js` | Логика: данные, подсчёты, фильтры, формы |

## Разделы

| Раздел | Что внутри |
| --- | --- |
| **Сегодня** | Плитки-итоги, ближайшие встречи и краткий вид недели — в две колонки, без прокрутки |
| **Календарь** | Неделя по дням, перелистывание, добавление встречи, раскрытие дня по часам |
| **Клиенты** | Карточки клиентов, фильтр по статусу, поиск по имени, телефону и почте |
| **Сессии** | Все встречи списком, отметка оплаты, удаление |

## Как запустить локально

Двойной клик по `index.html` — откроется в браузере. Ничего устанавливать не нужно.

## Как опубликовать и получить ссылку

Все три способа бесплатны. Папка целиком — это и есть готовый сайт: собирать ничего не надо.

**1. Netlify Drop — самый быстрый (нужен аккаунт, вход по почте или GitHub)**

1. Открыть <https://app.netlify.com/drop>
2. Перетащить папку `psy-crm` в окно браузера
3. Через несколько секунд появится адрес вида `https://имя.netlify.app`
4. В настройках сайта можно сменить имя на понятное, например `kabinet-demo`

**2. Cloudflare Pages**

1. <https://dash.cloudflare.com> → Workers & Pages → Create → Pages → Upload assets
2. Загрузить те же три файла, получить адрес `https://имя.pages.dev`

**3. GitHub Pages — если хочется держать код в репозитории**

```bash
cd psy-crm
git init
git add .
git commit -m "Кабинет: демо-версия CRM для психолога"
git branch -M main
git remote add origin https://github.com/ЛОГИН/psy-crm.git
git push -u origin main
```

Затем в репозитории: Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
Адрес будет `https://ЛОГИН.github.io/psy-crm/`.

## Что важно помнить

- **Данные хранятся в браузере зрителя** (`localStorage`), а не на сервере. Каждый, кто откроет ссылку, увидит демо-набор и сможет его менять — у себя, не у вас. Между устройствами данные не синхронизируются.
- **Не вносите реальные данные клиентов** в публичную версию. Всё, что введено на странице, остаётся в браузере того, кто вводил, но публичный адрес — не место для настоящих записей: сведения о психологическом состоянии относятся к специальной категории персональных данных.
- Перед использованием на реальных клиентах нужен сервер с базой, входом и правами доступа, плюс разговор с юристом про 152-ФЗ (хранение в РФ, согласие на обработку, уведомление РКН).

## Сохранение и выгрузка данных

Кнопка **«Данные»** внизу левого меню:

| Пункт | Что делает |
| --- | --- |
| Сохранить копию | Скачивает `.json` со всеми клиентами и сессиями. Это резервная копия — её можно загрузить обратно |
| Загрузить копию | Восстанавливает базу из ранее сохранённого `.json` |
| История изменений | Последние 10 состояний базы с возможностью откатиться к любому |
| Таблица для Excel | Два файла `.csv` (клиенты и сессии), кириллица с BOM — Excel откроет без настройки кодировки |
| Версия для печати | Сводка в новом окне: можно распечатать или сохранить в PDF |

JSON — для восстановления без потерь. CSV и печать — чтобы посмотреть глазами или показать другому человеку.

## Возможности

- **Главная в две колонки** — итоги, ближайшие встречи и неделя целиком на одном экране.
- **Календарь** — неделя по дням с перелистыванием, прошедшие дни бледнее. У каждого дня стоит число встреч; значок «пик» появляется только у по-настоящему плотного дня — от трёх встреч. На одной-двух его нет, чтобы не сбивать с толку. Клик по дню раскрывает его по часам: занятое время и свободное.
- **Добавление встречи** — из календаря на любом дне, с «свободного» часа или кнопкой «+ Встреча». В прошедшие дни добавить нельзя.
- **Поиск** — по имени, телефону и почте клиента. При вводе сам открывает раздел «Клиенты».
- **Режим сессии** — полноэкранный: таймер (чёрный в покое, оранжевый на ходу), карточка клиента, прошлая запись, план, заметка. Закрыл окно — вернёшься в ту же сессию с сохранённым черновиком.
- **Колода** — вопросы по шести темам на случай, когда застряла. Можно заменить своими, удаление с подтверждением.
- **Подсказки из данных** — «не был три недели», «не оплачено две сессии», «остался план».
- **Непрерывность** — план на следующую встречу виден в карточке клиента, в форме сессии и в режиме сессии.
- **Статусы встреч** — предстоит, идёт, проведена, не состоялась. «Не состоялась» не висит как идущая.
- **Режим «босс»** — иконка глаза скрывает имена, контакты, суммы и заметки; состояние запоминается.
- **Сохранение и выгрузка** — копия в `.json`, история изменений, CSV для Excel, версия для печати.
- **Постраничный вывод** — «Клиенты» и «Сессии» показывают по 12 записей на страницу, чтобы списки не разрастались в бесконечную ленту. Видно, какие записи открыты («1–12 из 21»). Поиск и фильтр по статусу сбрасывают на первую страницу.

## Демо-данные

При первом открытии подставляются пятнадцать вымышленных клиентов и двадцать одна сессия — чтобы интерфейс не был пустым.
Все телефоны и почты вымышленные. Кнопка «Сбросить демо-данные» внизу страницы возвращает этот набор.

**Демо не стареет.** Пока набор никто не правил, даты встреч при каждом открытии сдвигаются так, чтобы «сегодня» снова было сегодня: в календаре всегда есть текущая неделя, прошедшие встречи и будущие записи. Показать демо можно в любой день, даже через месяц.

Как только вы измените данные — добавите клиента, перенесёте встречу, загрузите свою копию — сдвиг прекращается навсегда: это уже рабочая база, и её даты трогать нельзя. Вернуть подвижное демо можно кнопкой «Сбросить демо-данные».

## Целостность данных

- **Загрузка копии проверяет содержимое.** Битые записи пропускаются, а не роняют приложение: в отчёте видно, сколько записей сохранено и сколько отброшено. Файл без единой целой записи не загружается вовсе.
- **Опорные поля приводятся к норме**: дата — только `ГГГГ-ММ-ДД`, время — только `ЧЧ:ММ`, суммы — неотрицательные числа, статус — из четырёх допустимых.
- **Встречи без клиента отбрасываются** при загрузке: в базе не остаётся записей, которые не к кому привязать.
- **Несостоявшиеся встречи не считаются долгом** и не портят подсказки.
